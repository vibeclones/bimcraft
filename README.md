# bimcraft (Vibeclones mirror)

Hosted copies of the browser (WebAssembly) builds of [bimcraft](https://github.com/getcadcraft/bimcraft), by CadCraft. The newest version lives at getcadcraft.com/use/bimcraft; this repo keeps older versions open-able so the timeline can be explored in a browser. This repo only mirrors upstream release zips; the code is theirs. Upstream license: Apache-2.0.

- Latest: `/bimcraft/latest/`
- Specific version: `/bimcraft/v<version>/`
- Version list: `/bimcraft/versions.json`

Each version folder is the unmodified contents of upstream's browser build zip from the matching release. A scheduled workflow mirrors new releases.
